# Machine Learning Model Comparison – Titanic Dataset

## Objective
Compare Logistic Regression and Random Forest models using the Titanic dataset.

## Models Implemented
- Logistic Regression
- Random Forest

## Evaluation Metrics
- Accuracy
- Precision
- Recall
- F1 Score
- Confusion Matrix
- Feature Importance

## Results
Random Forest slightly outperformed Logistic Regression in accuracy and F1-score due to better handling of non-linear relationships.
